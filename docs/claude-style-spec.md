# Claude 布局 + 春分谱品牌色 UI 改造规格（本次 UI 升级唯一基准）

> 目标：布局与质感照 **claude.ai 的极简风格**（衬线标题、去卡片化回答、居中 composer、色差分区、hairline 描边、慷慨留白），**配色一律沿用项目现有春分谱品牌色**，不引入 Claude 的米白/赤陶外来色值。
> 参考：Anthropic 官方 claude.ai 克隆规格（docs/anthropic-app-spec.txt 的 <ui_layout> 节）。
> 红线不变：图标一律真实图形（MaterialIcon/SVG），禁止文本充当图标；功能一律不丢；不新增 npm 依赖。

## 1. 色板（春分谱品牌色为唯一色源；变量名保持不变，原则上不改值，只补规格新要求的语义槽）

| 用途 | 品牌色 | 说明 |
| --- | --- | --- |
| 主背景（thread/页面） | `#FFFFFF` 纸白 | 现有 --background |
| 侧栏/嵌入表面/用户气泡 | `#EBEEE8` 皦玉 | 靠色差分区，不用边框线 |
| 文本主色 | `#12264F` 骐驶 | 现有 --foreground |
| 文本次级 | `#445B62` ink-soft | 现有 --muted-foreground |
| 文本弱化 | 沿用现有 textTertiary | 时间戳、占位 |
| 强调色 | `#B26D5D` 檀色 | 主按钮、发送键、选中态、聚焦描边 |
| 强调色 hover/深 | `#96564A` | 檀色加深一档 |
| 强调色浅底（选中/soft badge） | `#F3E9E4` | 檀色淡染 |
| 描边（hairline） | `#E0E0D0` 韶粉 | 一律 1px，极淡 |
| 链接 | `#3271AE` 青冥 | 引用链接等 |
| 成功/在线状态 | `#007175` 青雘 | 状态胶囊、成功提示 |
| 危险 | `#C83C3C` 朱磦 | 急危提示 |
| 警示 | `#BC836B` 紫磨金 | 保留 |
| 遮罩 | `rgba(18,38,79,0.32)` | 骐驶基调，无模糊或极轻 |

映射要求：tokens.css / globals.css **保持品牌色值**，仅补充/校正规格新槽位（accentSoft→#F3E9E4、遮罩、hover 深色 --color-accentHover 可新增变量）；shadcn 变量层同步核对；深色分支若有，保持现有品牌深色处理，确保可读。

## 2. 字体

- 标题/问候语：沿用项目现有 `--font-family-serif` 衬线栈，大小对比拉开（问候语 32-40px）。
- 正文/UI：system-ui 无衬线栈不变。
- 字号档位保持 2026-09-28 放大后的 125% 基准不动。

## 2.5 图标设计（参考 Claude 的图标语言）

- 统一使用 Material Symbols **Outlined 细线风格**（项目现有字体图标），视觉对齐 Claude 的细描边图标语言：尺寸 18-22px、线宽细、颜色跟随文本层级（主文本骐驶、次级 ink-soft），禁止实心彩色大图标块。
- 功能图标（历史/患者/分诊/摘要/导出/打印/发送/点赞/复制/朗读）保持现有语义名不变，只统一风格与颜色。
- 品牌符号：助手标识用 spa 图标小号呈现；不用彩色徽章底。

## 3. 布局（对照 app_spec <ui_layout> + claude.ai 实际）

### 侧栏
- 背景 `#EBEEE8` 皦玉，与主区**不用竖线分隔**（靠色差）；宽约 288px，可折叠。
- 顶部：**新问诊按钮 = 白底胶囊（rounded-full）+ 细描边 + 加号图标**，高度约 44px。
- 会话列表按时间分组（今天/昨天/更早，组标题小号弱化文字）；行 hover 韶粉圆角块，选中行白底或 #E0E0D0。
- 底部用户区：person 图标圆形 + 用户名，无边框，hover 反馈。

### 对话区（thread）
- 居中单栏，最大宽 **46rem（约 740px）**。
- 用户消息：右对齐，皦玉气泡（rounded-2xl，仅右上角小圆角 4px），无描边，文本骐驶色。
- 助手消息：**无卡片、无边框、无阴影**——去掉现有 .answer-card 白卡样式，改为纯文本块直接坐在页面上；助手名一行小字（图标+橘泉智养助手，衬线小标题感）；活动轨迹收成一行极简可折叠（图标+"活动轨迹 N 步"，展开才显示步骤）；分析摘要同样收敛。
- 引用列表弱化为小号链接行（青冥色）。
- 操作按钮（点赞/复制/朗读）：ghost 图标钮，**hover 才显现**（Claude 式），平时透明。

### 功能逻辑（参考 claude.ai 的交互行为）
- 新会话 = 问候语 + 居中 composer；发出首条后进入 thread 布局。
- 侧栏会话按时间分组（今天/昨天/更早），可折叠，行 hover 才显操作。
- 消息操作钮 hover 显现；生成中显示停止按钮（已有），流式渲染保持。
- 其余既有交互（分诊流、问诊步骤卡、摘要/导出/打印/录音/TTS）逻辑一律不动。

### 输入区（composer）
- 圆角 **24px** 大框，白底，1px 韶粉描边，聚焦时描边变檀色且 2px；内含 textarea + 左侧工具图标钮 + 右下圆形发送键（檀色底白色箭头图标，hover #96564A）。
- 宽度与 thread 同（46rem），贴底居中，下方免责声明一行 10.5px 弱化。
- **新会话未发首条消息时：composer 与问候语垂直居中于视口中上部**（Claude 首页式），发出首条后过渡到底部常驻布局。

### 欢迎墙（新会话态）
- 居中大号**衬线问候语**（如「今天想聊些什么？」，32-40px，骐驶色），上方一个小巧品牌符号。
- 其下正中是 composer（见上）；再下是三个模式入口改为**轻量建议卡**：皦玉底圆角块、无边框、图标+标题+一句描述，hover 变白底+韶粉描边，横向一排三张（窄屏纵排）。
- 不再使用大 hero 图标块。

### 弹层/对话框
- 白底 rounded-2xl（16-20px）、韶粉描边、柔影 `0 16px 40px rgba(18,38,79,0.08)`、遮罩按 §1；标题衬线。
- 分诊卡（TriageFlow）、问诊步骤卡（IntakeStepCard）：从"重卡片"改轻——白底圆角 16px、hairline 描边或无描边+浅影，选项选中态用 #F3E9E4 底 + 檀色描边/对勾，急危用朱磦。

### 按钮
- 主按钮：檀色底白字 rounded-xl（12px），hover #96564A。
- 次按钮：透明底韶粉描边，文本 ink-soft。
- 幽灵图标钮：无底，hover 皦玉圆角块。

## 4. 质感红线
- 禁用渐变、禁用重阴影、禁用彩色大色块（急危提示除外）；留白要慷慨，行高 1.65+。
- 全部硬编码颜色一律改为引用变量；组件内 <style> 块同步。
- **不得引入 Claude 外来色值**（#FAF9F5、#F0EEE6、#D97757、#B8552F、#F6E8E1、#E5E2D9 等一律不得出现在代码里）。
- 响应式与打印样式保持可用；三档字号模式保持可用。

## 5. 验收口径（复核员与主会话统一使用）
1. 打开 /chat 无会话：见居中衬线问候 + 居中 composer + 三张轻量建议卡，无旧 hero 墙。
2. 发送首条后：问候消失，thread 居中 46rem；用户消息皦玉气泡右对齐；助手回答**无卡片边框**。
3. 侧栏皦玉底无边框线，新问诊为白底胶囊。
4. 发送键为圆形檀色；聚焦 composer 描边变檀色。
5. 全局无渐变、无重阴影；配色只出现春分谱品牌色（檀/青雘/青冥/骐驶/皦玉/韶粉/朱磦/紫磨金），无 §4 列出的 Claude 外来色。
6. build + lint 通过；三档字号、打印、移动端断点可用。
