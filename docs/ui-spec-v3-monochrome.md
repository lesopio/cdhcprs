# UI 规格 v3：中性单色系统（参考 vercel/chatbot 与 mckaywrigley/chatbot-ui）

> 背景：用户对 v2 品牌暖色方案不满意（"配色真的好丑"）。经 GitHub 调研下载两份高星参考源码——
> `ui-references/vercel-chatbot`（21k★，Vercel 官方 AI 聊天模板）与 `ui-references/chatbot-ui`（33k★），
> 提取其设计体系作为本规格唯一来源。参考源码保留在 `D:\慢性病诊疗LLM\ui-references\` 供随时翻阅。
>
> 核心结论：好看的来源是**克制的无彩系统**——界面骨架零彩色（色度=0 的灰阶），主按钮近黑，
> 彩色只出现在功能性位置（链接、状态点、危险动作），再配极细描边、分表面阴影、微动效。
> 已修：侧栏"新问诊/激活项"双高亮（新问诊改近黑实底胶囊）。
> 红线不变：图标一律真实图形；功能一律不丢；不新增 npm 依赖；125% 字号基准与三档字号模式不动。

## 1. 色板（全部换成无彩中性色；换的是变量【值】，变量名不动）

参考换算（vercel globals.css 的 oklch → hex 近似）：

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 主背景 | `#FAFAFA` | 主区/页面 |
| 卡片/弹层/composer | `#FFFFFF` | 纯白 |
| 侧栏 | `#F7F7F7` | 比主背景深半档，无竖分隔线 |
| 文本主色 | `#1B1B1B` | 近黑（同时是 primary 按钮底色） |
| 文本次级 | `#525252` | 正文辅助 |
| 文本弱化 | `#8F8F8F` | 时间戳、占位、说明 |
| 幽灵 hover 填充 | `rgba(0,0,0,0.05)` | 侧栏行/图标钮 hover（参考用 black/6%） |
| 选中/激活填充 | `#EDEDED` | 激活导航项、用户气泡底 |
| 描边 | `#E5E5E5` | hairline 1px |
| 强调/主按钮 | `#1B1B1B` 底 + `#FAFAFA` 字 | hover `#3D3D3A` |
| 链接（引用/超链） | `#2F6FA8` | 唯一保留的功能蓝（原青冥微调） |
| 在线状态点 | `#3D8A5F` | 唯一保留的状态绿 |
| 危险/急危 | `#C0392B` | hover `#A93226` |
| 品牌 symbol（logo/spa 小图标） | `#B26D5D` | 全站唯一品牌彩点，仅此一处 |

- 原 v2 的檀色 #B26D5D / 皦玉 #EBEEE8 / 大面积青雘 #007175 / #96564A / #F3E9E4 全部退出界面骨架。
- 深色分支（.dark）：按参考 dark 值做齐（bg #262626 系、border #3D3D3D 系、primary 反白）。

## 2. 质感细节（参考的精髓，必须落地）

- **阴影分表面**（照抄 vercel tokens）：
  - card：`0 1px 3px rgba(0,0,0,.05), 0 1px 1px rgba(0,0,0,.03)`
  - float：`0 8px 24px -6px rgba(0,0,0,.10), 0 2px 8px -2px rgba(0,0,0,.04)`
  - composer：`0 1px 2px rgba(0,0,0,.04)`；聚焦：`0 0 0 1px rgba(0,0,0,.06), 0 2px 8px -2px rgba(0,0,0,.06)`
- **缓动**：spring `cubic-bezier(0.22,1,0.36,1)`、smooth `cubic-bezier(0.4,0,0.2,1)`；消息入场 message-in（fade+8px 上移 0.3s）、面板 fade-up。
- **加载态**：把"无限旋转图标"换成参考的 thinking-dots（三点跳动 1.4s）——发送中按钮、回答生成中一律用 dots；这是无限动画检查超时的根治。
- **滚动条**：4px 细滚动条，thumb rgba(0,0,0,.12)，hover .25。
- **字号层级**：UI chrome 小而精（侧栏项 13px 级、组标题 11-12px），正文 15-16px；在 125% 基准的 rem 下换算，不要写死过大 px。
- 圆角基准 10px（--radius 0.625rem），气泡 16px（右上 4px），composer 16px、欢迎墙居中态 24px。

## 3. 布局（结构不变，按参考细化）

- 侧栏 `#F7F7F7`：新问诊 = 近黑实底胶囊（白字+加号图标，44px）；导航项文字 `#525252`、图标弱化，hover 黑 5% 圆角块，激活项 `#EDEDED` 填充 + 近黑文字（与新问诊不再同形）；会话行 13px，hover 黑 5%，删除/改名钮 hover 才显现。
- thread 740px：用户消息 `#EDEDED` 气泡右对齐；助手无卡片直接排；引用行小号链接蓝。
- composer：白底 hairline 描边 + composer 阴影，聚焦切 composer-focus 阴影（不跳版）；发送键近黑圆形；欢迎墙居中态沿用现有结构。
- 欢迎墙：衬线问候 + 居中 composer + 三张建议卡改中性（`#F7F7F7` 底、hairline、hover 白底浮起 shadow-card）。
- 弹层/分诊卡/步骤卡：白底、hairline、float 阴影、选中态 `#EDEDED` 填充 + 近黑对勾；急危朱红淡染。
- 登录/首页：中性底白卡、近黑主按钮、去彩色。

## 4. 验收口径
1. 全站找不出一块"暖色/彩色"的大面（品牌 symbol、链接蓝、状态绿、危险红四处除外）。
2. 主按钮（登录、发送、开始问诊、提交并继续）全部近黑白字；hover #3D3D3A。
3. 侧栏只有激活项一处浅灰填充 + 新问诊一处近黑胶囊，无双高亮。
4. 加载态是 thinking-dots 不是旋转图标；全站无 1s+ 无限旋转动画（除保存的 reduced-motion 例外）。
5. 阴影/描边/滚动条符合 §2；消息入场有 message-in 微动效。
6. build + lint 通过；既有功能与三档字号、打印、移动端断点不回退。
